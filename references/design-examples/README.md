# Design Examples

Drop finished carousel exports (PNG/JPG slides or exported HTML screenshots) here as visual references for future generations — organized by niche, matching the folders in `/examples/`.

## Suggested naming convention
```
design-examples/
├── tech-startup/
├── wellness-brand/
├── finance-coaching/
└── creative-agency/
```

These serve as a visual style bank you or an AI model can reference for "match this look" style requests.
