# ✨ Trending Styles Reference

A rotating log of currently trending aesthetics to pull from when generating carousels. Update this file periodically as trends shift.

## Current Trends

### Glassmorphism
Frosted-glass panels, soft blur, subtle borders. Works well over gradient or photo backgrounds.

### Neo-Brutalism
Bold black outlines, flat high-contrast colors, raw/unpolished type — good for creative & Gen-Z-facing brands.

### Soft Gradients / Aura Backgrounds
Multi-stop pastel gradients, often blurred into soft "aura" shapes behind text.

### Isometric Illustration
Used heavily in tech/SaaS carousels for explaining products or workflows.

### Editorial Minimalism
Big serif headlines, lots of negative space, muted neutral palettes — common in personal branding and coaching content.

### Dark Mode Tech
Charcoal/near-black backgrounds with a single neon accent color, monospace or geometric sans headlines.

## How to Use
1. Pick a trend that matches the niche (see `NICHE_GUIDES.md`).
2. Pull matching prompt language from `PROMPT_LIBRARY.md`.
3. Apply the corresponding CSS variables/gradients from `references/color-palettes.json`.
