# Skill: ai-carousel-design-system

## Description
Generate professional social media carousels using trending design principles, consistent character references, and validated templates.

## Installation
```bash
npx skills add https://github.com/YOUR_USERNAME/ai-carousel-design-system
```
## Capabilities
- Generate image prompts for carousel slides
- Create HTML/CSS carousel templates
- Provide character reference sheets
- Apply trending design aesthetics
- Validate design consistency

## Usage Examples

### Generate Image Prompt
Input: "Create a 5-slide carousel for a tech startup about AI productivity"
Output: [5 detailed image generation prompts with consistent style]

### Generate HTML Carousel
Input: "Create HTML carousel for wellness brand, sage green theme"
Output: [Complete HTML file with inline CSS, responsive design]

## File Structure
- `/prompts/` - Ready-to-use prompts
- `/templates/` - HTML/CSS templates
- `/references/` - Design references
- `/docs/` - Documentation

## Design Principles
- Clean, minimal aesthetics
- Consistent typography hierarchy
- Strategic use of white space
- Trending color palettes per niche
- Mobile-first responsive design
