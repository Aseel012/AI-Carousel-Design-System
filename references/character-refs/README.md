# Character Reference Sheets

Store generated character reference images and their exact prompt text here so a consistent character/persona can be reused across a multi-slide carousel.

## Suggested naming convention
```
character-refs/
├── [persona-name]/
│   ├── front-view.png
│   ├── three-quarter-view.png
│   ├── profile-view.png
│   └── prompt.txt   <- the exact prompt used, for reuse
```

See `prompts/image-generation/character-references.txt` for prompt templates.
